Template Help Documentation

A complete customization and configuration manual for the **Apex Infrastructure Website Template**.

Introduction

Thank you for purchasing the **Apex Infrastructure & Construction Website Template**! This manual will walk you through setting up and customizing the template files. If you have experience with HTML, CSS, and basic JavaScript, editing this template will be simple.

Note: This is a static HTML5 template. It does not require database software, compilers, node packages, or complex configuration environments to run. You can deploy it instantly on any hosting provider.

Folder Structure

The files inside the Template/ folder are structured logically for quick customization:

Path Description
index.html The main layout structure of the website, containing all SEO parameters and schema markups.
assets/css/style.css Core style file, housing styling rules, breakpoints, and theme variable configuration.
assets/js/main.js Main JavaScript file executing slider animations, scroll events, statistics, and filtering.
assets/images/ Contains all optimized WebP photos and layout graphics.
assets/favicons/ Contains web icons, webmanifests, and Apple Touch Icon packages.
robots.txt & sitemap.xml SEO indexing configuration blueprints.

Getting Started

To run the template locally on your PC:

  1. Unzip the downloaded project package file.
  2. Locate the Template/ folder.
  3. Double-click the index.html file to open the website locally in your default browser.

To run with local staging server emulation for accurate form test simulations and speed validation, you can use Python or Node.js:

# Python http.server run (inside Template/ folder)
python -m http.server 8080

# Node.js http-server run (inside Template/ folder)
npx http-server

Changing Colors

The template uses CSS Custom Properties (CSS variables) for coloring. You can easily adjust the entire brand appearance by modifying these values in assets/css/style.css inside the :root block:

:root {
  /* Color Palette variables */
  --color-primary: #0f172a;        /* Deep Slate / Dark panels background */
  --color-secondary: #020617;      /* Solid Obsidian / Background headers */
  --color-accent: #d97706;         /* Architectural Amber / Accent color */
  --color-accent-hover: #b45309;   /* Darker Gold on hover elements */
  --color-accent-light: #fef3c7;   /* Light Gold Tint for tag highlight blocks */
  --color-text-body: #334155;      /* Dark Slate for body copy text */
  --color-bg-light: #f8fafc;       /* Light neutral section background */
  --color-bg-alt: #f1f5f9;         /* Cool Ice Gray section background */
  --color-success: #10b981;        /* Forest/Safety Green */
  --color-error: #ef4444;          /* Red validation alerts */
}

Recommendation: When changing hex codes, make sure you audit contrast ratings (using online testers like WebAIM Contrast Checker) to maintain accessibility compliance.

Changing Fonts

Typography is fetched via Google Fonts. To change the typography styles:

  1. Find the font links at the top of the index.html file: 
    <link href="https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700&family=Outfit:wght@400;500;600;700;800;900&display=swap" rel="stylesheet" />
  2. Browse and fetch replacement families on Google Fonts, copy the embed tags, and replace the old link inside index.html.
  3. Update variables in assets/css/style.css to match your custom family names: 
    --font-headings: 'Outfit', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;
--font-body: 'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;

Replacing Images

All demo images are hosted locally inside Template/assets/images/ as optimized .webp formats. To replace any images:

  • Simply save your new image with the same name and format (WebP) inside Template/assets/images/ to overwrite it automatically.
  • If you prefer to use standard JPEGs or PNGs, update the respective image source attributes (src or style.backgroundImage) in index.html and assets/js/main.js.

Tip: Always compress your custom images before deploying. Large images significantly slow down web load speeds and degrade search ranking metrics.

Contact Form Setup

Because static HTML templates cannot send emails directly, you need to configure the form to submit to a form processor backend. Below are the easiest ways to handle form submissions without writing server scripts:

Option A: Formspree (Highly Recommended)

  1. Create a free account at Formspree.io.
  2. Create a form inside Formspree dashboard, and copy the form endpoint URL.
  3. Locate the form in index.html, and add the endpoint to the action attribute: 
    <form id="contact-form" action="https://formspree.io/f/your_form_id" method="POST" novalidate>

Option B: Netlify Forms (For Netlify Hosting)

If you host your site on Netlify, they handle forms automatically. Simply update the form tag in index.html to include data-netlify="true":

<form id="contact-form" data-netlify="true" novalidate>

Deployment Guide

Deploying your website is easy. Choose one of the following methods:

1. Traditional Hosting (FTP/cPanel)

If you are using GoDaddy, HostGator, Bluehost, or similar providers, connect to your server directory using an FTP client (such as FileZilla), and upload all contents of the Template/ folder into the public_html/ directory.

2. Modern Static Hosting (Netlify / Vercel / GitHub Pages)

These modern platforms offer high speed deployment. Simply upload the files or connect your GitHub repository and point the build directory to the Template/ root. No build command is necessary.

Troubleshooting FAQ

Q1: The website is looking broken or styles do not load.

Ensure that the path of the stylesheet link in the <head> of your HTML is set correctly: href="assets/css/style.css".

Q2: JavaScript elements (sliders, details modals, or tabs) do not interact.

Make sure you have JavaScript enabled in your browser settings, check the browser console for file load errors, and verify the script source location at the footer: src="assets/js/main.js".

Q3: What are the support policies?

Refer to SUPPORT.md inside the root template folder to review FAQs, troubleshooting steps, and support parameters.
